# 🎵⚔️ **God of War Ragnarök Sound Tool** _v1.0.0_
[![GitHub All Releases](https://img.shields.io/github/downloads/iArtorias/gowr_soundtool/total.svg)](https://github.com/iArtorias/gowr_soundtool/releases)

### A small, powerful tool for extracting and repacking the sounds of **God of War Ragnarök**.

## 🛠️ Usage

1. Download the [latest release](https://github.com/iArtorias/gowr_soundtool/releases/latest)
2. Extract the release `.zip` file to a folder of your choice.
3. Use the tool to either extract or repack sounds.

### 🗜️ Extract Audio Files
```bash
gowr_soundtool --unpack <toc_file_path>
```

### 🗳️ Repack Audio Files
```bash
gowr_soundtool --pack <dir_with_wem_files>
```

## 📃 Compilation notes

- **Visual Studio 2022** is required to compile this project
